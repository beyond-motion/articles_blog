MotionHarness：专为 Agent 打造的视频动效精修工作台

查看原文 原文链接
点评最大的认知转变是：AI 做视频的瓶颈不在生成能力，而在可修改性与指代精度。过去默认「不满意就重生成」，其实是用概率手段处理确定性问题；一旦承认动效可代码化，就能把抽卡换成编辑。可迁移的方法有三条：把模糊指令翻译成位置、时间与数值；一次只改一件事；大改前留版本快照。这套「结构化指代加版本管理」同样适用于让 AI 改前端页面、PPT、剪辑时间线。下一步可验证：自己跑通 mh doctor、12 秒片头、单条标记只改一处，比较返工轮次与 token 消耗是否下降。
正文整理

MotionHarness 是一个面向 AI Coding Agent 的动效工作台：不让 AI 直接生成画面，而是让 Agent 写动画代码，工作台负责预览、时间线、点选标记、版本管理与导出。作者用一条 12 秒「周末计划」片头实测，全程未写 React、未碰 AE，靠「先读 mh skill」与精确的时间位置标记完成修改，并总结出三条少返工的习惯，同时说明其在终端门槛、平台兼容与适用题材上的局限。
