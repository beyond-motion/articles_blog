MinimaxH3 进入4K分辨率开源时代 768P草稿直接升2560 比官方还高清

查看原文 原文链接
点评旧认知是“开源模型只能做低分辨率，高分辨率属于闭源 API 的商业壁垒”；这篇材料把它改写为“壁垒是配方与工程细节，而非模型能力”。可迁移的判断有三点：一是能力解锁常发生在“草稿＋精修”的两段式结构里，而非单模型端到端；二是多个 LoRA 可以沿 rank 轴无损拼接，这意味着社区微调成果可叠加复用，二次开发成本大幅下降；三是加速必须报端到端数字，单算子理论值容易骗人。下一步可验证：在自己的 768P 草稿上跑三步流程，对比闭源 API 的细节保留度；以及测试 rank 576 合并后是否真的与三者串行等价。
正文整理

英伟达开源了 Open-H3-Regenerate-2K，是 MiniMax H3 闭源 2K 重生成 API 的首个可复现开放替代方案。流程是先用 H3 生成 768P（1344×768、121帧）草稿，再用该模型三步精修重生成到 2560×1440；单张 B200 上，5秒片热启动下标准前向需 73.11 秒，换 Sol 引擎并启用 Sol-Attn1、MXFP8 和 CUDA graphs 后降到 20.46 秒，端到端加速 3.57 倍。权重为合并 LoRA（FP32、rank 576）加 50 条 LMS Sharp 曲线的 AdaLN 分支，三个适配器沿 rank 轴拼接，合并误差 2.2e-8；Euler 三步采样、CFG=1，另附 MIT 协议的 3D 卷积 latent 上采样器。许可证有地域限制，排除欧盟、英国、韩国和美国。
