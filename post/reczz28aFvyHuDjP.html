分享这一年我的多 Agent 共享数据方法

查看原文 原文链接
点评旧认知是「换更强模型就能获得更好体验」，新认知是把 AI 能力拆成可迁移的个人资产层，模型只是可替换的执行器。可迁移的不只是工具用法，更是「先给 AI 造入口、再让 AI 改自己」的运行方式：用只读扫描出方案、人工确认后才动手、每次变更留 MANIFEST 与 undo，这套「AI 动手但后悔药在人手里」的流程可复制到任何批量重构任务。可验证的是：把资料迁到新 Agent 后，用 5 道固定问题；若它答不出，就说明上下文真的缺了东西，这比感觉更可靠。
正文整理

作者把自己半年来的个人 harness 项目 build-your-harness 升级到 2.0：harness 指模型之外让 AI 能干活的那整套结构，包括工程环境和用户自定义的上下文文件夹。2.0 新增 star（原地重组目录并以 MANIFEST 与 undo 脚本兜底）、AGENTS.md 统一入口加 NOW.md、TOOLS.md、know（拉取社媒数据生成个人画像）、sync（限额过滤后 git 推送到云端跨设备）、better（38 项体验加换 Agent 迁移自测）。
