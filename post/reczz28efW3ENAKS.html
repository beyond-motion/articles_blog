再见了反重力，Google 又来搞事了

查看原文 原文链接
点评旧认知是「要用某家模型就得进它的客户端」，于是 MCP 常驻服务被视为标准答案；读完会发现，无状态 CLI + 自描述 schema + 一段规则文件提示，能以近乎零的上下文成本实现同等甚至更灵活的集成，把「换工具」变成「加外挂」。这一模式可迁移到任何能力提供方：把服务做成可组合的原子命令，而非霸占入口的应用。下一步可验证：在自己的 AGENTS.md 里写入调用规范，实测生图、PDF 分析、后台 Deep Research 三条链路的落盘路径与 interaction ID 串联是否稳定，并对比常驻 MCP 的 token 与延迟开销。
正文整理

文章介绍 Google DeepMind 开源的 gemini-api-cli：一个用 Go 编译的零依赖、无状态单文件命令行工具，不抢占主交互入口，而是作为 Claude Code、Codex 等现有 Agent 的底层外援，按需调用 Gemini 的多模态生成、文档分析、后台 Deep Research 等能力。文章对比了它和 T3 Code、gemini-cli 三种调用方式的定位差异，讲解了安装、API Key 鉴权与 Pro、Ultra 订阅赠金领取规则，并给出把调用规范写进 AGENTS.md 后由宿主 Agent 自动调用的实操流程。
