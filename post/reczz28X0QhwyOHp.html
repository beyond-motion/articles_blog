Papers with Code 以 Apache 2.0 许可开源

查看原文 原文链接
点评旧认知是「好用的学术工具只要存在就一直可用」，实际上它们的生死取决于母公司的产品决策；可迁移的判断是：依赖单一平台的科研基础设施，应优先看它是否开源、是否有公开 API、数据能否被外部重建。这一框架也适用于其它被收购关停的排行榜、数据集索引和文献工具。下一步可验证的点：仓库的自动导入覆盖度与原排行榜的差距、MCP 服务器能否被本地 agent 直接调用、以及社区在数月后的提交活跃度是否足以支撑长期维护。
正文整理

原 Papers with Code 是整理 AI 论文及其代码、模型、数据集、任务与基准排行榜的社区资源，被 Meta 收购后于 2025 年关停，域名一度重定向到 Hugging Face 的 Trending Papers，排行榜随之消失。如今它以社区协作项目形式在 huggingface/paperswithcode 重新开源，采用 Apache 2.0 许可，技术栈为 Python FastAPI 后端加 React 前端，单一 monorepo 管理，部署在 Hetzner VPS，并通过从 Hugging Face、arXiv、GitHub 自动导入保持内容更新，同时公开 API 与配套 MCP 服务器。
