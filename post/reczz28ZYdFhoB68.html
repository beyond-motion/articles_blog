Opus + Blender + Remotion：一个人也能开的角色动画工作室

查看原文 原文链接
点评旧认知是「角色动画=团队+Maya+排期」，或「让模型随便做个动画」；新认知是产能瓶颈已从制作能力转移到方案约束力——brief 写得越窄，AI 产出越可用。可迁移到任何 AI 生成型交付：先把需求钉成边界文档，再让工具链分段执行，最后用最小样片验证闭环，而不是一次性追完整成品。下一步可验证两点：用 12 秒单笑点样片跑通全链路耗时与返工点；把 brief 模板固化为可复用资产，并核对 Remotion 商用授权条款后再对外报价。
正文整理

作者光年用 Opus 写导演方案（brief），通过 MCP 插件 mcp-for-blender 让 Claude Code 操作 Blender 完成场景搭建、绑定与关键帧，再用 Poly Haven 的 CC0 HDRI 打光，最后用 Remotion 的 Agent Skills 合成标题、声音并导出成片。五个步骤跑通一个人做角色动画的最小闭环，并给出最少配置清单与接单报价、授权注意事项。
