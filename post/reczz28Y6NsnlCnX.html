作者回应读者关于 Grok bot 订阅时机的提问，认为可以入手了。xAI 推出把 Twitter、Cursor、Grok bot 与 Grok 打包的四合一订阅，分为 $8、$30、$100、$200 四档，用量分别是 Plus 的 1、4、15、50 倍。核心变化是 xAI 与 Cursor 的 API 积分合并，Cursor 第三方模型额度大概率缩减，而 Grok bot 在 $30 以上档位至少翻倍。作者建议：此前通过 bug 订阅 $99 会员的老用户不要更换；错过旧方案、主要想玩 Grok bot 的新用户则值得换。
