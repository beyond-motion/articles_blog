html版剪映来了：html-video正式开源

一句话总结

当视频可以写成代码，剪辑软件就退化成播放器。 下一批爆款工具，不是给人用的，是给 Agent 用的。 开源不是放弃赚钱，是放弃'卖铲子'，改收'过路费'。

核心摘要

nexu-io 团队开源的 html-video 项目，让用户用写 HTML 的方式制作动画视频，支持 Claude Code、Cursor 等 AI 编程助手直接接入，20 多套风格模板，本地渲染导出 MP4，Apache-2.0 免费商用。

点评html-video 的意义不在"写代码做视频"，而在于它把视频从"时间轴的黑箱"变成"可读可改的文本"——创作从感觉驱动转向上帝视角的精确控制。真正值得关注的是"Agent 原生"这个信号：工具默认的用户不是设计师，而是 AI Agent，当视频可以写成代码，剪辑软件就退化成播放器，下一批爆款工具是给 Agent 而非给人用的。
正文整理

nexu-io 团队开发的 html-video 的开源项目在 GitHub 正式上线，号称，只需编写 HTML 就能快速生成高质量动画视频，让 AI Agent 彻底告别传统视频剪辑软件。该项目目前已开放 20 多套精选顶级视频风格模板，涵盖产品宣传、知识解说、数据可视化、标题卡等多种常见场景。核心亮点：Agent 原生：支持 Claude Code、Cursor、Codex、Hermes 等主流 AI 编程助手直接接入，即写即用。分页编辑 + 故事板：像写文档一样组织视频内容。本地导出 MP4：基于 Hyperframes + Chromium + FFmpeg 技术，本地渲染，无需云端费用。完全开源：Apache-2.0 协议，免费商用。html-video 旨在让用户用写代码的方式做视频，让视频制作像开发软件一样可控、高效且便宜。安装方式与地址放在评论区。
