Datasette Lite 用 Service Worker 和 Pyodide 运行完整应用

查看原文 原文链接
点评旧认知是“浏览器里跑 Python”只是演示级玩具，只能渲染静态 HTML；读完会意识到关键差异不在 Python 能否运行，而在请求由谁接管：web worker 只能旁路模拟，service worker 才能进入请求链路。这可迁移到任何想在前端复用服务端框架的场景，例如本地优先工具、可分享的缺陷复现链接、插件演示环境。下一步可验证：用一个 lite.datasette.io 链接固定 Datasette 提交、SQLite 版本与插件组合，检查 JS 可视化插件在 service worker 模式下是否真正执行，并观察 CORS 约束的边界。
正文整理

Simon Willison 完全重写了 Datasette Lite，用 service worker 配合 Pyodide 和 WebAssembly，在浏览器内运行完整的 Datasette Python 应用。新版支持加载 SQLite、JSON、CSV、SQL 脚本，可选择 PyPI 上已发布的 Datasette 版本、GitHub 提交/标签/分支、100 多个 SQLite 版本，并通过 PyPI 或 wheel URL 安装插件。相比 2022 年初版用 web worker 模拟请求、并以 innerHTML 注入 HTML 导致 JS 功能失效，service worker 解决了这一根本限制。
