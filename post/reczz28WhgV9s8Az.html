Anthropic 的 Duet 开始干活了

查看原文 原文链接
点评旧认知是用输出质量或能力上限评价 agent；读完后评价维度换成三条：可观测性、可撤销性、可度量性。可迁移的做法包括：把权限从提示词搬到代码，任何人都无法「说服」agent 变通；把自动化从个人账号解耦，避免离职或登录过期让任务静默失效；用异源模型互评替代自评；把清理类工作变成公开计分板以调动注意力。下一步可验证：为自己的高频任务建一个小评分集，先定义「好」再改提示词；列出高风险动作清单，标成「必须先问」；给每个 agent 任务设定可检查的产出形态与记录。
正文整理

Every 周报围绕两种与 agent 协作的路径展开：Dan Shipper 测评 Anthropic 的全天候个人 agent Duet，称其为目前最好的个人 agent；Willie Williams 则复盘为何砍掉个人 agent 产品 Plus One，重建为 Slack 里的公司共享 agent。文章附上 13 个可复用技能：让 agent 的工作容易被检查、把权限写进代码、让两个模型互评、用 Dot 盯频道与代办。最后以 Mike Taylor 的 DSPy 主张收尾：先定义「好」，再谈优化。
