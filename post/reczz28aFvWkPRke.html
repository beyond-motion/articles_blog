刚用 Magpie 干翻 CC Switch，又一人单挑 Anthropic！这哥们做的 Alma 把 Claude Code 甩在身后！

查看原文 原文链接
点评最大的认知增量是把注意力从“模型强弱”转向“运行时工程”：同一个模型换一套提示词编排、工具接口与重试策略，通过率就能拉开差距，Agent 的竞争力常常长在 Harness 而非模型上。其次学会用 Cost per Pass 而非 token 单价评估工具，因为低花费可能只是提前摆烂。可迁移到工具选型、评测设计与自建 Agent：先看框架层能力，再比模型。下一步可验证的是装 Alma，用同一批任务对比自己常用工具的实际通过率与单次成本。附带一层产品启发：yetone 先撞墙再拆墙，个人痛点是最可靠的需求来源。
正文整理

文章以 FrontierHarness v1.1 排行榜切入：该基准不测裸模型，专测 21 款 Agent 工具的 Harness 运行时，按 Cost per Pass 与通过率排名。yetone 独立开发的 Alma 以 1.04 美元/次、64% 通过率冲进前三，压过第 17 名的 Claude Code。随后介绍 Alma 的本地优先 Harness 与 herdr 图形客户端双身份，涵盖多模型直连、内置浏览器、Artifacts、Skills、MCP、语义记忆、终端会话折叠与手机远程批复。
