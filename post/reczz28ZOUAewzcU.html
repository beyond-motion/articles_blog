综合性能全球第一！海马云自研 RH Upscale 超分模型正式登陆 RunningHub

查看原文 原文链接
点评旧认知把超分当成“拉分辨率 + 加锐”，读完应改成：超分是一场受约束的生成式补全，核心矛盾不是清晰度而是“补多少细节”与“偏不偏移内容”之间的权衡。可迁移到一切生成式修复场景——老照片、音频降噪补全、文档/代码补全、医学影像增强——判断标准都应是保真约束下的信息补全，而非观感刺激。产品层面还提示：把质量-成本做成连续档位，比只做一个“最强模式”更能进入真实生产链路。下一步可验证：用自己的人物特写与夜景素材对比 Ultra 与 Max 的人脸一致性与连续帧闪烁；接入 API 后测端到端（生成→超分→编码）总耗时，核算批量任务的单位成本。
正文整理

海马云自研视频超分模型 RH Upscale 首发并接入 RunningHub。在统一 540P 升 1080P 的 13 个配置横评中，Ultra 以 0.539 分获综合质量第一，Max 档对 5–10 秒视频做 2 倍超分仅需 34 秒。产品提供 Ultra 至 Low 五档模式覆盖精品成片到批量预览，采用内容保真约束下的时空联合重建架构，支持 AI 生成、实拍与压缩素材的画质增强及 API 调用。
