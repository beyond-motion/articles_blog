刚刚，Muse迎来了一次大更新！

查看原文 原文链接
点评旧认知是：AI 硬件要靠一个惊艳的新形态去替代手机，Humane AI Pin 就是这条路。这篇文章把它翻过来：失败的根源是自建供应链成本较高、电池发热受限、应用生态难以短期重建，并非形态不够新。可迁移的判断是：在需求高度分散、形态尚未收敛的品类里，掌握标准与接口，把制造和场景试错外包给生态，比垂直整合更划算。这也解释了为什么开源固件和 SDK 会成为入口争夺战。下一步可验证：ESP32 与 Linux 两条链路的实际接入门槛、连接器生态的提交量能否持续转化为硬件侧活跃项目，以及 Home Link 是否会变成智能家居的新控制入口。
正文整理

Meta 开源了 Muse Gadgets，让开发者把个人 AI 助手 Muse 接入树莓派、ESP32 开发板等硬件。项目由三部分组成：ESP32 固件、Linux SDK 和官方配件 Muse Home Link；官方给出四种参考形态：树莓派桌面终端、AMOLED 触控小屏、HDMI 电视棒、彩色墨水屏看板。代码以 Apache 2.0 开源；发布当天，社区就用墨水屏和 50 美元开发板做出了演示。文章把 Muse Gadgets 与 Humane AI Pin 的道路做对比，指出软件与硬件解耦的模块化生态，可能比自造专用整机更务实。
