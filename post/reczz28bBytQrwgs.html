gbro-cover-design：文章丢进去，三轮问答直接给你一套封面提示词

查看原文 原文链接
点评它改变了一个旧认知：让 AI 画图总要改八版提示词，问题往往不在生成端，而在需求澄清缺少结构。可迁移到任何「AI 产出前需对齐需求」的场景——PPT、落地页、视频脚本、UI 稿，都能用几轮固定提问把模糊想法压成 brief。同时它示范了一种边界意识：工具只覆盖链路一环，选型时要看清它交付的是提示词而非成品，否则会误判能力。下一步可验证：拿自己 3–5 篇旧文各跑一遍，对比「自己手写提示词」与「三轮问答」的返工次数和实际耗时，看省下的十几分钟是否稳定成立。
正文整理

介绍开源 Skill gbro-cover-design：把文章丢给 Agent 后，它先读内容，再分三轮提问——第一轮定构图与封面标题，第二轮确认人脸参考图、产品截图等素材，第三轮问清表情、背景色调、字体字色，未指定部分交给模型自行处理，最后输出一段可直接生图的完整提示词。内置 10 套构图风格并按文章内容推荐，画幅固定 3:4，本身不生图；文中给出 Claude Code 与 Codex 的安装方式，并提醒不要漏拷 references/ 目录。
