Anthropic 值 2 万亿美元吗？

查看原文 原文链接
点评旧认知是「高毛利 + 高留存 = SaaS 式好生意」，读完后应改成：把训练算力当作生产成本后，这更像内容生意（半衰期六个月的「好莱坞」），服务时享受软件毛利，维持竞争力时承受硬件毛利。可迁移到任何「能力快速折旧 + 长期成本前置、短期收入后置」的行业，如影视、制药、芯片。下一步可验证：下一次模型发布后的环比增速是否重现降价带来的跳升、巨鲸客户占比是否继续下降、以及训练成本是否真如研究人员所说呈对数增长。
正文整理

作者基于 Anthropic 的 S-1 招股书拆解其 2 万亿美元估值：公司累计融资 1411 亿美元、仍握有 1317 亿美元现金，单季收入 168 亿美元，净收入留存率约 900%，报告毛利率 85%。但真实客户约 250 家、收入高度依赖 Claude Code 与少数巨鲸客户，训练算力若计入成本则毛利率仅 45%，且未来数年有上千亿美元不可取消的算力承诺。结论是：估值赌的是「Claude 持续领先」这一信念，而非当期财报。
