正文整理

介绍 GitHub 开源项目 free-claude-code（15k+ star）：在本机运行一个代理，把 Claude Code 发出的 API 请求转发给指定的免费或本地模型，例如 NVIDIA NIM、OpenRouter、DeepSeek、Kimi、GLM、Ollama、LM Studio 等。只需改两个环境变量即可切换后端，Claude Code 本体与 VS Code 插件无需改动，/model 选择器照常可用，并带本地 Admin UI 面板。还支持按 Opus、Sonnet、Haiku 三档分别映射到不同模型，其中重推理走云端、轻任务走本地。作者提醒免费额度有速率限制，重度使用建议本地模型保底处理。
