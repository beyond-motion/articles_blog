五一节爆了！DeepSeek 版 Claude Code开源了！

Datawhale干货 

开源项目：DeepSeek-TUI

「鲸鱼兄弟们好」

这个五一假期，一个美国独立开发者发了张图，用中文写了一句：

鲸鱼兄弟们，谢谢你们。

「鲸鱼兄弟」是 DeepSeek 粉丝的自称。他用这个词，感谢了一群把他的开源项目推上 GitHub 热榜的中国开发者，现在已经星标 2.7k+。

他叫 Hunter Bown，一个美国人，不是 DeepSeek 团队的人。

但他写的项目，叫 DeepSeek-TUI。

就是 DeepSeek 版的 Claude Code：一个用 Rust 写的、住在终端里的编程 Agent，背后跑的是 DeepSeek V4。

国内开发者过去一年对 Claude Code 的心情，大概可以用一个词概括：眼馋。

现在有个老外，用 DeepSeek 做了一个同款——开源，免费。

更让人意外的是这些细节。

打开 release 页面，发布包托管在阿里云 OSS 和腾讯云 COS 上——GitHub Release 在国内下载有多慢，开发者都懂。Hunter 不在中国，但他研究过这件事。

图片：来源内容未完整抓取

他还用 DeepSeek 把宣传推文翻译成了中文，给国内用户写了专门的中文 README。

他在推特上说，这是他人生中最疯狂的两天。

它是 DeepSeek 版的 Claude Code

DeepSeek-TUI 的设计很简单：Claude Code 的形态，DeepSeek 的内核。

Claude Code 那一套，它都搬过来了——文件操作、shell、git、网页搜索、子智能体、MCP 服务器，连 Anthropic 主推的 SKILL.md 技能机制都原样支持。操作模式三档：Plan（只读探索）、Agent（每步确认）、YOLO（全自动放行），工作区有 Git 快照兜底，翻车了也不慌。

图片：来源内容未完整抓取

而 DeepSeek 的特性，它用满了：

思维链直接流式输出——你能在终端里看着它一边想一边写代码。

1M token 上下文默认开——跑长任务不断片。

一个叫 RLM 的设计很「DeepSeek」——既然 V4 Flash 价格只有 Pro 的三分之一，那就让一个主模型并发指挥 16 个 Flash 子任务同时跑。便宜的活交给便宜的模型，账单立刻下来一截。

安装一行命令搞定：

npm install -g deepseek-tui

Linux、macOS、Windows 都有预编译二进制。

再翻一下这个项目的提交记录,贡献者列表里有 Claude、Gemini、Qwen、Cursor、GitHub Copilot。

其中 Claude 一个就提了 150 多次 commit。

一个独立开发者，用 AI 辅助编程，给 AI 写了个辅助编程框架。

作者没有学过计算机

到这里你大概会以为，能把 DeepSeek 玩出这种花样的，应该是个程序员。

他不是。

Hunter 没学过计算机。

**

图片：来源内容未完整抓取

他学的是音乐：音乐教育专业，本科加硕士，毕业之后真的去当了三年乐队指挥。

后来他读了 MBA，又拐去法学院专攻专利法。

写代码是更后来的事。他自己说，这不是转行，"更像是几条线最终汇到了一起"。

而他的曾祖父，是贝尔实验室的研究副总裁、无线电先驱——业余时间喜欢自制蜡筒，跑去卡内基音乐厅录音。一个搞科学的，业余玩音乐。

一百年后，他的曾孙在专利法的课堂上意识到，自己正走在一条和先祖反过来的路上。

他在自己的个人网站上，留了这样一句话：

他是科学家，爱音乐；我是音乐家，爱科学。
