DeepSeek 新 API 真好用！一键把公众号/知乎等文章导出成 Markdown

查看原文 原文链接
点评旧认知是「网页转 Markdown」需要装插件或写爬虫，还要自己处理正文抽取；这篇提示模型厂商正在把「网页理解」做成一次几厘钱的原子能力，个人开发者只需做体验层。可迁移的场景：RSS/播客转写、论文与财报入库、客服知识库同步、竞品内容监控。下一步可验证两件事：一是 Fetch 对强反爬站点（小红书、部分公众号）的成功率与失败计费边界，二是把抓取结果接进向量库后，检索质量是否真的优于手工复制。同时要记住它的短板——本地单页意味着无同步、换设备即丢，重要内容必须及时导出。
正文整理

作者 Chris 基于 DeepSeek 新推出的网页抓取接口（Fetch，输入链接返回标题与 Markdown 正文），做了一个纯前端单页工具：配置自己的 API Key、批量粘贴公众号/知乎/小红书链接、一键抓取成 Markdown，并支持分栏编辑与预览、多文章切换、单篇导出或打包 ZIP。API Key 与编辑状态只存本地浏览器，不上传服务器；官方定价约 0.005 元/次成功请求，失败或空正文通常不计费。
