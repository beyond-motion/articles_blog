腾讯这个搜索 Skill，我想让它在 Agent 里常驻

查看原文 原文链接
点评旧认知是「搜索只是个工具调用，接上就行」；读完会意识到搜索是 Agent 最重的基础设施之一，成本主要藏在内容质量、去重、时效和权威性判断上。可迁移的场景包括：自建 RAG 前先评估外部检索基座、把「信源可控」作为 Agent 产品的设计参数、以及用模糊自然语言而非关键词来设计用户入口。下一步可验证的是：在自己的 Agent 里对比自建搜索与元宝搜索在同一批任务上的准确率、Token 消耗与端到端时延，并测算 2000 次免费额度之外的成本是否支撑其作为默认搜索服务。
正文整理

作者在做墨问 Agent 时发现，搜索接口接通只是第一步，真正的难题是结果准确性、内容质量、网页过期、转载去重和信源引用。腾讯把元宝搜索的搜索理解、优质内容收录、质量筛选与排序封装成服务，通过 Skill、MCP、API 开放给开发者。作者接入后测试了模糊剧情找片名、限定官方文档查 Python 版本差异、核对政策三个日期等任务，认为其自然语言理解、信源覆盖、检索范围可控和 300 毫秒级响应值得常驻在 Agent 里。
