六一宠粉节：氪200刀，乔帮主开源8个工具、5个精选Skill，统统免费！

最近 AI 圈有点沉寂，前有 Gemini 3.5 Flash 拉胯，后有 Opus 4.8 不及预期。

唯有 Codex App 最近几次更新深得我心。

冲了 200 刀会员后，Vibe Coding了一堆自用小工具，做了几个新 Skill。下面逐个介绍，免费开源送给大家，工具超多，页面很长，建议收藏再看。

Chrome插件

乔木快捷提示词

发现身边很多朋友还是不太会写提示词，于是写了个Chrome插件，把过去一年多写的提示词都放进去了。另外收录了好友苍何（canghe）整理的几百套 GPT-Image-2 提示词，自带效果预览。最后从 Github 精选了500个常用提示词，覆盖开发、设计、营销场景。

你只需要一键复制粘贴，或简写自动补全就能在任意网站和 AI 平台用。也能添加日常快捷语，比如收货地址、邮箱等，任何有输入框的地方都能用。

  • 插件安装地址：https://chromewebstore.google.com/detail/乔木快捷提示词/ndfmbdiaclladmoeifbhlkacllmfhjej
  • 项目开源地址：https://github.com/joeseesun/Qiaomu-QuickPrompt

乔木 Tab

每天上网，打开浏览器的次数是最多的，每次都要新开 Tab，这个页面值得好好利用。除了添加常用网站，也支持创建Todo、添加便签、查看天气预报、搜索查看最近关掉的 Tab页面、收藏夹等。每个模块都可以控制显示与否，也支持 Command + K 唤起，快速搜索或设置。

如果选了ChatGPT，输入内容后按Enter，自动跳转官网获得答案，不需要二次复制回车。

  • 开源地址：https://github.com/joeseesun/qiaomu-tab
  • 预计本周上架 Chrome 应用商店

乔木 X 发布器

X（前Twitter）的文章发布工具太难用了，不支持Markdown表格渲染，图片要手动一张张传，相当耗时。改造了一版，把插件和自己的博客打通，同步博客文章，一键发布到 X。

  • 插件地址：https://chromewebstore.google.com/detail/xposter/iimkimodgdjnnmdopeolboakhjmhfbbj?authuser=0&hl=zh-CN
  • 推荐关注小小东：https://x.com/xiaoxiaodong01

乔木单词学习

基于开源的类沉浸式翻译插件 read-frog，让Codex开发了一套单词学习系统。每天阅读英文网页收藏的单词，变成闪卡可复习，基于艾宾浩斯曲线遗忘曲线。增加单词学习模式，根据单词难度（如CET6+）旁边加上中文翻译，标记掌握情况。

  • Read-frog项目：https://github.com/mengxi-ream/read-frog
  • 乔帮主改造版：https://github.com/joeseesun/qiaomu-english-learn

各种网站

艺术家风格网

调用 GPT-image-2 API，用几百个艺术家名字生图，然后整理成一个网站。

  • https://style.qiaomu.ai/
  • 即梦版本：https://jm-style.qiaomu.ai/
  • 开源代码：https://github.com/joeseesun/qiaomu-artist-style

乔木音乐网

开发者以前是摇滚青年，组织过北京高校乐队演出，也曾在「无名高地」酒吧打工过一年。开发了个网站，放几十首自己精选的 Suno 生成音乐，后面歌曲会持续更新。

  • https://music.qiaomu.ai/
  • 开源地址：https://github.com/joeseesun/qiaomu-music-player-web

乔木博客

  • https://blog.qiaomu.ai/

乔木HTML分享

把 AI 生成的 HTML、Markdown、SVG、Mermaid 变成一个微信里能阅读的网页，一键免费部署到 Cloudflare。

  • 开源地址：https://github.com/joeseesun/quickshare-cloudflare

乔木Skill

乔木论文解读

支持原始 TeX Source 格式，抽取图表更精准。只需提供 Huggingface 和 Arxiv 论文网页地址就行，不需要提供 PDF 地址也能解读。

  • 安装：npx skills add joeseesun/qiaomu-paper-interpreter
  • 开源地址：https://github.com/joeseesun/qiaomu-paper-interpreter

乔木阅读助手

用飞书 + AI 辅助读书，划线就能对话！

  1. 让 Codex 或 Claude Code 把 Epub 电子书按章节写入飞书文档
  2. 人肉阅读，有感触的地方划线、加粗，最好评论

  3. 让 Codex 读飞书文档中的标记和评论，让AI解释回复你

  4. 安装：npx skills add joeseesun/qiaomu-read-helper

  5. 开源地址：https://github.com/joeseesun/qiaomu-read-helper

Suno音乐制作

把任意想法变成一首歌，不用登录网站，通过CLI或Computer Use方式创作。Skill 内置了5000多种音乐风格和 Suno 歌词创作提示词。支持下载任意 Suno 歌曲，下载时可以带 LRC 歌词。

  • 开源地址：https://github.com/joeseesun/qiaomu-suno-master
  • 安装：npx skills add joeseesun/qiaomu-suno-master

Suno 音乐 MV

用 Codex 生成图片，再结合 Hyperframe 生成幻灯片感 MV，配合 GASP 动效和字幕。

  • 安装：npx skills add joeseesun/qiaomu-mtv-creator

NotebookLM 处理器

支持任意内容传到 NotebookLM 处理成播客、PPT、思维导图等，目前快 5k Star 了。

  • 开源地址：https://github.com/joeseesun/qiaomu-anything-to-notebooklm

其他工具和资料

乔木脚本

油猴脚本集，包括：Youtube网页一键复制字幕、小宇宙网页版倍速播放、小红书粘贴图片上传、公众号跳转即梦生成封面按钮等。

  • 开源地址：https://github.com/joeseesun/qiaomu-userscripts

GEO相关

今年出版了《AI营销：从SEO到GEO》，也顺利举办了中国第一届GEO大会。最近整理了《GEO红皮书》《GEO蓝皮书》。

  • GEO公开课资料：https://xiangyangqiaomu.feishu.cn/wiki/Bvx6wmAqAirtR1kWejmcFFrGn6f

两个小技巧

让你的Codex越来越聪明

阅读并检索所有 Codex 对话记录与执行日志，进行系统性复盘，提炼出可复用的经验文档，保存为独立文件并在 .agent 配置中引用加载。

制作PPT小技巧

  1. GPT 5.5 Pro和Grok搜索获取参考资料
  2. 让 Codex 或 CC 加工，提炼方法论、添加金句，写成经验贴，输出 Markdown
  3. 把 Markdown 上传到 Youmind，先生成大纲，再生成20页高清PPT页面

  4. 导出zip图片压缩包，依次粘贴到Keynote中

  5. PPT生成提示词：https://xiangyangqiaomu.feishu.cn/wiki/QUmxwep0diOUOnkrdGscVa1PnE7
