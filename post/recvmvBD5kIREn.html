小红书支持上传 skill 了，AI 创作者赚钱的时机到了

原创 空格丶

2026年5月28日 13:27

小红书悄悄上线了一个新能力：上传 skill 在笔记里直接挂上。

用户可以上传自己原创或收藏的 skill，关联到笔记，读者看到 skill，一键复制口令，扔给自己的 Claude Code / Cursor，几秒钟就装好用上。

这是继腾讯推出 SkillHub 之后，又一家大厂下场做 skill 社区。

现在，Skill 被小红书做成了一个标准功能，

这似乎没什么惊讶的，毕竟用户已经习惯在小红书讨论 AI。

但要是今天知乎、B 站把支持把 skill 挂在内容下，反而让人觉得奇怪。

所以，今天我更想聊一下，为什么小红书能做成 AI 讨论度最高的社区。

01 大厂正在密集入场 skill 这件事

去年这个时候，提示词特别火。

那波热度里，大厂动静比较小。我印象里只有火山引擎认真做了个提示词管理工具，剩下大部分大厂都在隔岸观火。

到了今年，skill 明显不一样了。

腾讯先出了 SkillHub。现在小红书也跟上了。

skill 比提示词更受重视，skill 的能力大得多。更容易交付。更容易传播。更容易变现。

从大厂密集入场这件事看，至少未来一段时间 skill 会持续盛行。

并且 skill 会变得越来越规范，安全性、原创保护提升，也能给创作者带来关注量以外的收入。

哪怕模型能力继续进化，skill 还是会像提示词一样，发挥很长一段时间的余热。

02 为什么小红书来做这件事，特别合理

小红书在我看来一直是一个跟进用户需求技术发展、有创新的社区产品。

我经常在即刻发帖称赞小红书的一些亮点新功能，很多功能可以说是社区类产品首创，就像这次的 skill 上传，就是响应社区用户热点内容而来的。

他能兼容任何形式的创作，让创作者持续的发光发热，

GitHub、SkillHub 这种地方上传一个 skill，是一个冷冰冰的文件夹。你点进去，看到的是 readme、是代码、是几个 md。

但同一个 skill 放到小红书：

  • 博主可以发视频、配图文讲清楚使用场景
  • 评论区有真实用户讨论翻车点、Tips、二创玩法

你能直接看到一个 skill 在不同人手里被玩出什么花样

小红书的内容生态刚好就是干这件事的。

03 用户视角：复制口令，几秒装好

先看看这个 skill 在用户侧是怎么用的。下面是归藏老师的笔记截图。

复制下来是这样一段话：

请先检查是否已安装 RedSkill 商店，若未安装，请根据https://fe-video-qc.xhscdn.com/fe-platform-file/104101b8320fbtcp4620653u0hejenq0004pf88gk8rtde.md安装 RedSkill 商店，但是只安装 CLI，然后安装 space-weread-analyzer 技能。若已安装，则直接安装 space-weread-analyzer 技能。

你把这段口令扔给你的 Claude Code / Cursor，它会自己读文档、装好 CLI、再装上对应的 skill。

从这段口令也能看出来小红书的实现思路：自建了一个 skill 文件仓库，博主上传 skill 文件，用户通过 skill 唯一标识名定位安装。整套架构其实不复杂，但用户体感非常顺。

04 创作者视角：怎么上传一个 skill

再讲一下创作者怎么上传。

上传必须在网页端完成，App 暂时不行。

步骤是这样的：

  1. 进入小红书创作���务平台
  2. 选择「Red Skill」入口
  3. 上传一个 skill.md 文件，或者一个包含 markdown 的文件夹
  4. 系统自动解析名称、介绍、md 内容，填一个编号
  5. 提交审批

审批通过之后，你在发笔记的时候会多出一个组件，可以关联你已经审核通过的 skill。

笔记发出去，读者就能看到复制按钮。

目前只能解析 markdown 文件，脚本类的文件会被过滤掉。

如果你的 skill 是纯 md 工作流，问题不大。如果你的 skill 依赖 Python / Node 脚本，就只能等小红书后续放开了。

上传 skill 的功能目前还在灰度，但复制口令功能每个人都能用。

我自己已经传了几个 skill 上去，配套笔记也发了。官方说现在有流量支持。

05 小红书 skill，可能真的让创作者开始赚钱

我做 skill 内容做了两个月，体感非常明显

小红书一篇 skill 笔记，几千点赞、几万阅读是常态，私信和评论里全是真实用户在交流怎么用、用出了什么效果。

它天然把"效果"放在最前面。视频、图文、评论区的真实案例——你是先被效果打动，才去装的。

并且有完整的创作者激励体系，比如店铺门槛做的很低。

skill 本质上是一种内容资产。它和图文、视频一样，可以带来：

  • 粉丝：你的 skill 用过的人会关注你
  • 流量：好 skill 会被官方推到更大的池子
  • 变现：粉丝沉淀下来之后，接广告、做付费内容、做服务都是顺理成章
  • 品牌：你的 skill 用得人越多，你在这个垂类里的影响力越大

过去两年我看到很多技术博主有好东西但变不了现，最大的问题是：

好工具没有好场景去触达普通用户。

小红书把这个创作者需要的场景闭环了。

06 AI 对社区平台的价值

AI 行业的技术迭代速度是真的快。一个模型更新，连带着各个大厂、我们平常用的服务、整个行业都跟着动一遍。

新鲜事多、信息密度高、讨论热度永远不减。

这就是 GitHub、X、Reddit 这些海外社区，靠着 AI 这一波又兴盛了一次，甚至很多不用这些社区的小白用户因为 AI 也开始使用了。

到了国内，公众号、小红书这样的平台，是 AI 原创内容和信息丰富度最好的地方。

这一波 AI 的讨论度，让平台、创作者、用户三方都拿到了红利：

  • 平台：拿到内容、活跃度、下一代用户
  • 创作者：拿到流量、粉丝、变现机会
  • 用户：拿到信息、工具、���实可用的经验

而像 skill 这种能直接被使用、被复用、被二创的内容资产，会是下一波 AI 内容里增长最快的形态。被用的东西，传播力远超过被读的东西。
