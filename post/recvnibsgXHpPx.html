以陈平安为师，我想记录一下每周在这世上遇到的好句子。

每周读到的好句子，收下来晾一晾——是以有「读」。

心里总有话忍不住想对这个世界讲，——是以有「说」。

说

problem > solutions

人很容易爱上自己的解决方案，而忘记了「问题」才是我们的目标。

新开了一个旅游的有限游戏：

以冰箱为画布，以每个省博物院代表文创为要素，完成拼图🧩。

  1. 模型很喜欢说「想象一下」

  2. 现在很多 Agent 都支持多模态能力

可以加一条规则：「每当你输出“想象一下”时，直接生成配图，并在图中标注信息，方便直观呈现你想要表达的画面」。

很多人的痛苦不是解不了题，是根本没有属于自己的题。每天在解别人出的题：老板的、社会的、家庭的。

找到自己为之痴迷一生的谜题，好像就拥有了一方小天地，随时可以钻入其间，不断思考它，琢磨它，推进它。

那颗躁动不安的心，被安顿下来了。

每个月做一个「主题阅读」，可以把自己泡在该学科领域的语境 context 之中，体验下来，有两个收获：

  1. 掌握该学科的地图（有哪些主要问题、分别有什么结论）

  2. 用该学科视角来看待世界。信息在该学科中是如何分析处理的。

AI 对 孩子的帮助，至少有三个角度可以立马落地：

  1. 媒介：把要学习的知识，通过各种媒介形态（图片、视频、游戏），多角度加深理解

  2. 梯度：针对每个孩子对要学习知识的理解水平，生成符合「最近发展区」难度的题目，让孩子可以收获最大的学习信号

  3. Build：边学边玩边创造。把自己所学到的，再创造出游戏、网页、小程序等等，分享给他的同学们，收获正反馈，养成 build 的心态和习惯。

所谓「在场」：全然地处于此时此地，而非活在对过去的反刍或对未来的焦虑中。

一个作者写得笨拙但真诚，那个笨拙本身就在告诉我们：他想说的比他能说的更多，他在语言的边界上够不着某个东西。

这个「够不着」的姿态是动人的。

人事合一时，人不去想“意义”，做事就是做事，想做就做了。“哪那么多矫情”

人与事出现割裂时，那个间隙，让人开始琢磨“意义”问题。“我是谁？我在哪？”

我的笔记系统中有一个文件，记录一些没想明白的问题，比如：

  1. 未来，AI 的入口会在哪里？

  2. Agent 想要什么？

书

本周推荐书籍《鱼不存在》。

Lulu Miller 的父亲从小告诉她，宇宙没有意义，“混沌是唯一确定的事”，「你不重要」。虚无主义向她袭来袭来，她需要自救寻找解药。

她找到一个看起来从不绝望的人当样本：David Starr Jordan，一个一生给鱼命名、收藏一次次被砸碎、却一次次重建的人。Miller 想搞清楚：这种不被混沌打倒的本事，是不是有解、值不值得学。

之前大家以为“秩序、笃定、分类”是对抗混沌的解药和美德；Miller 说：不对——你强加的分类（鱼、人的等级）是虚构，而那份不容置疑的确信正是作恶的引擎；松开分类、“放掉鱼”，才是自由与善的所在。

「鱼不存在」这四个字的真正意思是：你最确信的那些分界线——包括那条给人的价值排高下的线——是你自己画上去的虚构。松开它们，世界不是塌了，是变大了，变温柔了，变真了。Miller 说，放掉“鱼”那一刻，她得到的是天空、是海、是此前那条线挡在外面的一整片。
