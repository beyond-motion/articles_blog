Spiral 4.0 发布：全面拥抱智能体原生

查看原文 原文链接
点评读前会默认AI写作工具是“你打开它、与它对话”的应用；读后意识到下一形态是“被智能体调用的基础设施”，产品竞争点从界面体验转向协议接入与可编程性。另一个增量是定价逻辑：限额应跟随真实消耗形态，而非表面会话数，否则重度单轮用户与API用户都会被误伤。可迁移到任何SaaS：先问“我的产品能否被智能体直接调用”，再用盲测裁判为风格与质量建立可量化的反馈闭环。下一步可验证：接入MCP后智能体产出是否真接近本人笔迹，以及token定价是否让成本更公平。
正文整理

Spiral 4.0 发布，核心是三项变化：一是基于文体测量学重建风格引擎，学习用户写作指纹，盲测中87%的AI草稿能混入本人样本；二是新增 MCP 支持，连同 CLI 与 API 让智能体可在任意工作流中调用 Spiral 写作、个性化与去AI腔；三是推出团队工作区共享风格与草稿。因智能体原生用量激增，定价从会话次数改为按 token 计费，基础价下调10美元。
