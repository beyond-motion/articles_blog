开采你生活中的上下文

查看原文 原文链接
点评旧认知把 AI 写作理解为“对着空白页让模型生成”；读完后应改成：AI 的第一价值是从你已有的语料中“开采”，生成只是最后的整理动作。可迁移场景很广——用户访谈、客服通话、团队周会、个人日记，都可以先建可搜索库，再让智能体按具体成果物提取。另一个增量是“限定来源”这条提示原则：防幻觉不靠换更强模型，而靠约束输入范围，让草稿只由你说过的话构成。下一步可验证两件事：本周把智能体接到 Slack 与 Notion，用文中提示语提取某主题的全部历史观点并分组标注出处，对比从零生成的质量；同时用屏幕行为分析找出自己最大的注意力漏点并设定下降目标。
正文整理

文章讨论如何把会议记录、消息、笔记和清晨念头变成可搜索的个人上下文。AI 创业者 Noah Brier 把 Claude Code 接入数千条个人笔记，当作研究、思考与写作的第二大脑；Every 增长负责人 Austin 则用 Codex 的屏幕记录功能分析自己每天被 iMessage、Slack 打断的次数，找回深度工作时间。文章还给出一套三步工作流：默认全收集、打通所有信息源、明确成果物并限定只从本人已有表达中提取，最后强调工具再强也替代不了人的目标感与判断力。
