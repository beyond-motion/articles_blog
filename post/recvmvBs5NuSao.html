用 AI 三年多，我发现这 6 种交付物可以完全交给 AI 了

原文链接：https://mp.weixin.qq.com/s/kqJEciYf4J3jaDLWBs-PEw

最近问了身边十几个朋友怎么用 AI。

绝大多数还是同一个模式：自己先写一版，然后丢给 chatbot 改写润色。

Agent 是最近几个月才发展起来的，很多人还没有把习惯切换过来。 chatbot 干不了 Agent 的活，比如让模型端 100% 交付PPT、文档、Excel、视频、图片、网页。基本覆盖知识工作者里的全部场景。

为了让大家把 Agent 用好，我把用 AI 的方式，大致分成了五级。

第一级：自己操作 PPT 这类软件，让 AI 帮着填每一页、每一段的内容。

第二级：完全通过对话和 AI 交互，让它直接输出指定格式的交付物。

第三级：把日常稳定产出的内容 Skill 化，让 AI 用 Skill 一句话产出。

第四级：多个 Skill 串联或并行，让 AI 在一次任务里调动多个能力组合交付。

第五级：套上自动化工具（Agent 自带的定时、n8n、openclaw 这些），让上述场景移动化、自动化执行。

大多数人用户还停在第一级和第二级之间。从第三级开始，就要依赖 Agent 的能力了。

这篇文章用最近刚刚大更新的天工超级智能体，演示下从第三级到第五级的全过程。

使用天工的原因很简单，它有 Agent 的框架，支持图片视频多模态能力，还有 openclaw 接入飞书的能力。方便我演示 Agent 制作不同场景下的交付物。

天工这次大版本升级，把 OpenClaw 那套完整的智能体能力整个搬上了云端：不用本地部署、不用配 API、不用单配主机，注册就能用。

多模态能力全面覆盖：视频、图片、文档、表格、网页、PPT，一个对话框统一派发。

是我目前用过的门槛最低，多模态能力最强的 Agent 产品，这也方便我给大家演示 PPT、视频、图片的制作。

下面就把Agent的三级应用场景、边界能力，使用效果给大家讲透了。

第一层：这些任务可以完全交给 Agent

下面列 6 个手里几乎 100% 可以丢给 AI 的任务。

整个过程就是，描述任务，天工出第一版，我在用他们这次也更新的多模态编辑器，做最后判断和精修。

每个任务先把使用场景写清楚。天工就能调用相关的 Skill，来输出和我们日常工作一致的交付物，方便我们修改和分享。

1 PPT

假设你临时接到一个任务：明天要给新来的产品经理做一场 AI 工具培训。在对话框里输入这句：

🪄 根据我过去写的文章，给产品经理做一份关于在工作中有效使用 AI 工具的培训 PPT，10 页左右，要有工作流示意图和分步骤布局

出来的版式审美和配图协调度是目前我用过最舒服的中文格式。

每个文字、每张图都可以在线编辑器里改，可以导出 PPTX、PDF、HTML 。

2 调研文档

假设你要给甲方交一份 AI Agent 赛道的市场调研报告，发送下面提示词：

🪄 做一份 AI Agent 行业 2026 年的市场调研，重点看竞争格局、商业模式、未来 3 年的机会点，输出 PDF + Docx

天工的 Agent 在云端服务器里跑，每个用户都有一个自己的虚拟电脑来做网页深度搜索、抓资料、做验证。

最后交付回来一份竞争格局梳理清楚、商业模式拆解到位、机会点有理有据的稿子。

最好用的还是，文档编辑器直接划词就能编辑，改个标题，开头结尾，就可以直接交付了。

3 图片

我给这篇文章制作了一个封面，就是用的天工Agent。在对话框里输入这个：

🪄 制作一个简约手绘风格，2.35：1 的封面图，必须包含文字"用 AI 三年多，我发现这 6 种交付物可以完全交给 AI 了，"

然后，天工给了张构图干净、文字排版到位的封面就出来了。不满意的地方可以直接在画布编辑器里改字、抠图、换素材，出图和定稿在一个窗口完成。

我对上面图片觉得不是很满意，少了一些icon 的点缀，于是提了点优化，最后得到下面那张图。

4 表格

把一堆上千行的 CSV 变成可洞察的结论。

🪄 按利润表、资产负债表、现金流量表分别拆，找 3 条亮点和 3 条风险，最后给一句话结论

接着还能把下面的表格，让它做成可视化的 HTML 财务分析，一站式输出所有想要的内容形式。

天工内置的 Microsoft Excel 形式的编辑器还能让你实现线上编辑，AI辅助修改。

5 网页

假设你想做一个能挂在简历里、放在社交平台 bio 里的个人介绍页

比如我就让 天工 根据我在即刻上发布的一些动态，生成了一份关于我的个人介绍。

这块依赖的模型代码能力，以及调用的 Skill，让整体设计审美水平完胜大模型直出的效果。

6 视频

有一些时候，新品发布的物料包，里面要塞一支 15 秒预告片。

这次我直接在天工出视频。生成完不用导去剪映，内置的时间线编辑器里就能改剪辑、加字幕、调滤镜，一个画布从头改到出片。

天工 AI 接入了 Seedance 2.0、Kling 3.0、Pixverse V6，按需切旗舰模型和轻量模型。还可以根据需求选择你想要的模型。

这六种交付物是绝大多数知识工作者会使用到的。

以前要在 好几个软件之间反复横跳，飞书写文档、Keynote 做 PPT、Figma 画图、Excel 跑数、剪映剪视频。

现在这些文件的输全在天工的对话框下就能实现。

把这步跑顺了，效率提升至少 3 倍。

但它还不是终点。

第二层：把常做的事沉淀成 Skill

Skill 可以让你每次都不需要输出有多有长的提示词来获得交付物，天工提供了三种使用 skill 的方式。

把日常重复做的事用自然语言描述给天工，我每周都要写一份小红书选题，要看最近三天的热点、对照我的账号定位、产出 5 条带切入点的选题。

Skill Agent 直接帮我打包成一个固定流程，下次只要喊"跑选题 Skill"就能调用。

天工还可以根据你日常的对话，为你建立专门属于你的Skills。

3 Skill 会越用越懂你

Skill 跑多了，你自然会对它输出的内容，提出意见，你的意见就是对 Skill 下一次的优化，用的越多，Skill 就优化的越好。

我改过的版本、我倾向的风格、我删过的部分，它都在学。

一个 Skill 跑两周以后，输出的东西基本不用改了。

但 Skill 还有一个局限。

它依然要我主动来操作指挥它。

我希望它在我没喊的时候也能干活。

第三层：给 Skill 套上定时器和飞书 IM

这是最爽的一层。

天工现在支持下发定时任务，并且能直接接入飞书。

1 对于定时任务

每天早上 8 点，天工自动跑一次"过去 24 小时 AI 行业动态"的搜集，按大模型发布、产品更新、行业融资、论文突破、政策动态分类，挑 5-8 条最重要的，按固定排版推送到飞书。一觉醒来打开飞书就能看完。

2 接入飞书移动化办公

接入飞书后，和养龙虾的体验是一样的，走在路上，躺在沙发上也能指挥Agent 来干活。这个功能用了就会回不去了。

电脑不在身边的时候，发一句"帮我分析这个 CSV 的数据趋势"，云端立刻跑起来，结果回传到飞书里。

到这一层，工作模式就彻底变了。Agent 不单纯是 AI 工具的状态，是一支 7×24 小时上班的云端团队。

天工过去一年在国内没怎么发声，他们一直在全球最卷的 AI 市场上竞争。

这次升级把打磨成熟的全球旗舰架构直接接入国内版本，有了"跨代际"的感觉。

体感上的差别就是：别家还在小步迭代功能，天工直接交付了一个满级形态。

旗舰模型这块尤其爽。DeepSeek V4 Pro、GLM-5.1、K2.6、Qwen3.6-Plus 全都支持，可以手动切，也可以让它"智能调度"自己挑。

我以前要同时订几家图片、视频模型厂商的 token plan，现在在这里一个账号全包了。

价格方面是按积分来扣的，用多少，扣多少。
