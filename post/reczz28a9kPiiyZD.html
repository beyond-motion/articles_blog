在 WorkBuddy 里就能查你的微信聊天记录，我们把 vchat CLI 开源了

查看原文 原文链接
点评纠正的旧认知：以为这类工具的难点是总结与排版（长图、杂志风日报），其实那只是最后一段，瓶颈在底层取数；一旦取数被标准化成 CLI 接口，产品形态就从「一个日报」跃迁为「任意 AI 可编排的数据源」。可迁移到一切数据锁在本地客户端的场景：邮件、笔记、IM、健康与账单数据，都应先做无状态 CLI，再叠 Agent 与 skill。下一步可验证：跑 vchat doctor 确认链路、用 corpus export --stream 导出全库做本地检索、用 watch 接一个自动化触发器。
正文整理

作者把「群日报」的底层取数能力抽出来，开源为 vchat CLI：解密并查询本地微信数据，提供 60 多个子命令，覆盖聊天记录、成员头像、语音转写、朋友圈、公众号、统计与实时监听，且全部支持 --json、可作 Python 包调用。文中给出手动与「让 Agent 代装」两条安装路径、在 WorkBuddy 中 18 分钟实测，并强调仅限处理本人有合法访问权的数据。
