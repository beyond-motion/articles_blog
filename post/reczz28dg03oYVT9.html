Ladybird 首个 alpha 发布：macOS 与 Linux 可直接安装

查看原文 原文链接
点评旧认知是：浏览器引擎是巨头才能做的重工程，新项目只能长期停留在源码阶段。读完后的增量是：alpha 的真正意义不在功能完整，而在把「可安装、可报错、可量化」三件事同时打通，让外部反馈成为引擎进化的输入。可迁移到任何自研底层系统的冷启动：先降低试用门槛，再公开可对比的基准，最后把失败路径产品化（一键报错、崩溃报告）。下一步可验证两点：一是 WPT 增量中 AI 代理贡献的可持续性，二是 serviceWorker 这类平台 API 缺口的修复速度，它们决定 Ladybird 能否从「能跑」走向「能用」。
正文整理

Ladybird 发布首个 alpha，macOS 与 Linux 用户可直接安装而无需自行编译。项目自研 HTML 解析、CSS 引擎、布局、JavaScript 与 WebAssembly 等核心组件，仅复用 HarfBuzz、Skia、ffmpeg、SQLite 等外部库。Simon Willison 试用后评价速度很快、界面轻量，WASM 视频压缩和 Pyodide REPL 可用，但 Datasette Lite 因 serviceWorker.startMessages 报错，已提交 issue。2026 年 10 月的更新将样式与布局移到独立线程、引入新 JS JIT，WASM 引擎在 JetStream 3 上提升 7 倍，WPT 通过数增至 2,184,722 项，官方称多数增量来自 AI 编码代理，同时提醒 alpha 阶段仍会崩溃和站点不兼容。
