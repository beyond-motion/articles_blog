DeepSeek 推出按成功请求计费的搜索与抓取 API

查看原文 原文链接
点评旧认知是「搜索 API 拼的是覆盖度和结果质量」，读完会发现对代理场景而言，计费口径和失败成本可能比质量更先决定选型。可迁移的判断框架是：任何面向代理的基础设施，都要看它是否把「无效调用」从账单里剔除——这决定了代理能否大胆重试、多轮检索。下一步可验证三点：一是实测 Search 结果的相关性与反爬稳定性是否配得上低价；二是核算「成功计费」在真实重试率下的综合成本，而非只看单价；三是观察搜索 API 是否会因 SEO 与代理流量竞争走向补贴甚至负价格。
正文整理

DeepSeek 在其 API 中新增搜索（Search）与抓取（Fetch）接口，定价为每 1000 次请求约 0.75 美元（5 元人民币），且只对成功请求计费，Search 返回按相关性排序的结构化结果列表。服务面向需要联网检索的 AI 代理与 RAG 开发者。Hacker News 讨论中，评论者以 Brave（5 美元/千次）和 Kagi（12 美元/千次）作对比，认为其价格低一个数量级；同时有人质疑实际场景价值，指出 SearXNG 等自建方案对个人更划算，并认为这类服务存在的前提是 Google 不提供付费通用搜索 API。
