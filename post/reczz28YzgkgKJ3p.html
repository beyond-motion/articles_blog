Google 推出 Gemini Decisions API 与 Decision 1 模型

查看原文 原文链接
点评旧认知容易把「决策模型」理解为替你做决定的黑箱，读完会发现它更像一个受约束的打分器：问题形式被限定在三类，输出是概率分布而非结论，阈值仍由业务方定义。这一认知可迁移到风控、内容审核、工单分流、A/B 判定等任何需要把模型输出接进 if 语句的场景——先问输出是概率还是布尔，再决定谁来承担误判成本。另一个增量是选型框架：模态广度、价格、接口约定构成可量化的三角，而非笼统的「谁更强」。下一步可验证：同一批多模态样本在三家模型上跑同一组问题，观察概率校准是否稳定、阈值漂移有多大。
正文整理

Google 发布 Gemini Decisions API 与 Decision 1 模型，正式加入由 Jev 和 OpenAI 开辟的「决策模型」赛道。该接口沿用 Jev 的 Noul 命名，支持是/否、多项选择、评分量表三类结构化问题。定价与 GPT-6 Luna 相同，每百万输入 token 10 美分，输出免费，Jev 仍以 4.2 美分最便宜。输入模态上 Gemini 覆盖文本、图像、音频、视频与 PDF，为三家最广。Simon Willison 用机器人视频实测四个是/否问题，Gemini 返回概率值而非二元结果。
