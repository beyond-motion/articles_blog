Vibe Check: Duet—Anthropic's Always-on Agent

查看原文 原文链接
点评读完后需要修正的旧认知是：个人代理的胜负手不在模型强弱，而在「是否记得住、跟得上、会主动开口」这套状态管理能力；Dot 的退化说明常驻代理的可靠性会随产品迭代波动，用户迁移成本其实很低。可迁移的场景包括：评估任何常驻型 AI 工具时，优先考察任务闭环率、异常时的主动提醒机制、以及对自有工作流的可接入性（如连接器、会话调度）。下一步可验证的是：Duet 的清单与频道机制在真实多线程工作中能否长期维持不失真；当它无法触达自定义连接器时，用户是否会退回手动补位，从而抵消其主动性带来的收益。
正文整理

作者 Dan Shipper 原本是重度 ChatGPT 用户，依赖 OpenAI 的常驻代理 Dot 处理日程与任务，但 Dot 近期变得不主动、开始丢任务（如税务处理未完成也未提醒）。在获得 Claude Duet 早期访问后，他试用两周，使用比例已接近 ChatGPT 与 Claude 五五开。Duet 是 Anthropic 独立应用形态的全天候个人代理，运行于 Opus 5.5，定位知识工作者与小企业主的「幕僚长」，能把重复话题拆分到频道、维护任务清单、在应用内编辑文档与仪表盘。作者也指出其局限：无法指挥电脑上的 Claude 会话、邮件草稿弱于 Dot、定时任务触达不到自定义连接器、暂无真正语音模式。
