我用 Grok Bot 打通了公众号排版到发布

查看原文 原文链接
点评旧认知把 AI 写作工具等同于“生成文字”，这篇材料指出真正的杠杆在于把已有的 CLI 或 API 工具包装成 skill，让 Agent 操作真实系统。提示词的重点从“做什么”转向“不要做什么”：不要在日志显示密钥、先预览再落地、只建草稿。这套方法可迁移到任何带 CLI 的平台：先做 doctor 或 validate 前置检查，再逐步执行并保留人工确认点。下一步可验证两件事：把“不创建草稿”写进指令后，Agent 是否会遵守这一边界；以及高级排版模块是否真能在不改动正文意思的前提下提升阅读体验。
正文整理

作者极客杰尼用 Grok Bot 跑通公众号从排版到发布的全流程：先安装 md2wechat skill 并读取能力清单，再通过安全入口配置 AppID、AppSecret 与 API Key 并做校验，然后用 Bot 自带图片能力生成封面与信息图，选 X 书签文章试跑，先发预览、不满意用高级排版模块重排，最后只创建草稿不群发，一分钟内进入公众号后台核对。
