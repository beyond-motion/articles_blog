DeepSeek 发布全家桶应用 API

查看原文 原文链接
点评旧认知把 API 理解为模型推理能力的出口；这篇材料提示，API 也可以是产品级体验的整体交付，模型只是其中一个部件。可迁移的判断是：任何已有 C 端产品的团队，都应把自研打磨出的交互链路视为可售卖的 API 资产，并识别自家哪些工作是重复的基础工作。下一步可验证：用开源 Demo 跑通一条链路，与自建检索解析管线比较人力和时延成本；测算工具调用费在总成本中的占比；观察参数化编排是否削弱可调优空间，形成黑盒。
正文整理

DeepSeek 将 App 对话体验背后的能力打包开放为 API：在原有接口中开启参数，即可获得联网搜索、深度思考搜索、文件输入、阅读链接与安全风控，工具调用与上下文拼接由服务端自动完成。V4.1-Flash（deepseek-flash）在 Messages、Responses、Chat Completions 三个接口下支持这些能力；Search、Fetch、OCR、ASR、TTS 也可作为独立接口单独调用。官方同时开源轻量前端 Demo，支持导入历史对话。定价为 Token 费加工具调用费。
