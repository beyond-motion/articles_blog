Mistral 发布 Voxtral 3 与实时语音代理 SDK

查看原文 原文链接
点评旧认知把语音 AI 的竞争看作单个模型的 WER（词错率）和参数规模之争；读完后应转向“链路完整度 + 部署形态”的竞争：谁能把语音识别、推理、工具调用、语音合成四段压进可接受的延迟里，且能落在客户要的部署位置上，谁就赢。可迁移到任何 agent 类产品的评估：先看链路缺哪一环，再看单点指标。下一步可验证三件事：Voxtral 3 的首字延迟与打断响应；工具调用在真实业务系统中的错误率与越权风险；上一代开放权重模型在本地设备上的实际吞吐，是否仍是被闭源方案排除者的最优退路。
正文整理

Mistral 发布 Voxtral 3 语音模型及实时语音代理 SDK，后者将聆听、推理、工具调用与语音输出整合为实时链路，可在电话或网页上对话并调用业务系统完成任务。官方称覆盖 50 多种语言，支持 EU 托管与自部署，但未公布参数、许可证与基准。社区怀疑新模型已闭源，同时有开发者验证上一代开放权重的 Voxtral Mini 4B Realtime 仅需 4GB 显存即可在普通核显笔记本上超实时离线运行。
