Cursor 市场 Claude Code 扩展遭篡改

查看原文 原文链接
点评它改写的旧认知是‘从正规渠道装扩展就安全’——安全边界不在开发者身份，而在发布密钥的持有者与市场的审核强度。这一视角可迁移到 npm/PyPI 依赖、CI 插件、模型权重与二进制分发等所有‘可信名字 + 第三方通道’的场景，提醒我们把供应链当作需要验证的一环而非背景设施。可进一步验证的动作：立即在开发机检查 authorized_keys 是否含 svc-telemetry，清点团队所用扩展的来源与版本锁定策略，并为 SSH 登录入口补上日志与异常告警，同时关注 Open VSX 等镜像市场是否同步受影响。
正文整理

Cursor 市场上一个被篡改的 Claude Code VS Code 扩展曾公开可下载约 11 小时（太平洋时间周四 2:27–13:35），恶意版本会向受影响用户的 ~/.ssh/authorized_keys 追加标记为 svc-telemetry 的 SSH 公钥，形成可持久化的远程登录后门。Anthropic 的 Felix Rieseberg 称这不是 Anthropic 系统或员工电脑被攻破，官方渠道发布的版本未受影响，事件仅波及 Cursor 用户；Cursor 估计最多约 5000 人受影响，已暂停扩展市场，并给出用 grep 自查 authorized_keys 的检测方法。
