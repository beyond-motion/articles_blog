官方点名，DeepSeek Harness 的 4 个神级插件。

查看原文 原文链接
点评旧认知是「AI 编程助手只管生成文本和代码」；读完会发现客户端正在变成可被插件重写的「Agent 操作系统」，瓶颈从模型能力转向流程编排与可观测性——Token 花在哪里、主 Agent 与子 Agent 如何分工，都能被量化展示。这套思路可迁移到内容团队流水线、回归测试自动化、科研文献管理等场景。下一步可验证：装 dsh-context 定位自己最耗 Token 的环节并优化；用 paiwarp-dsh 把一次手工终端测试改写成提示词，比对录屏证据与人工结果是否一致。
正文整理

文章指出 DeepSeek Harness 调用官方 API 的日活已达 154 万，第三方插件突破 3.5 万个，官方从中点名表扬了 4 款：自媒体工作台 dsh-media-desk（选题、成稿、排期、复盘全流程）、归藏设计 dsh-guizang-design（统一视觉规范并去 AI 味）、上下文洞察 dsh-context（拆解 Token 构成与子 Agent 分工）、论文阅读 agentero-dsh（本地文献库、PDF 与笔记）。作者还自制自动化终端插件 paiwarp-dsh，让 Agent 驱动真实终端并自动截图录屏取证。
