Tailscale 开源 Tailcat：不用注册，即用即抛，内网穿透工具

查看原文 原文链接
点评读完后会改变“内网穿透必须注册、组网、长期稳定”的旧认知：对机器对机器、一次性任务而言，连接本身可以像临时凭证一样被创建和丢弃。这个思路可迁移到 Agent 沙箱、CI 任务、远程调试、Demo 演示、临时文件传输和家庭 NAS 访问。下一步可验证：tcpG 地址的过期与撤销机制、地址泄露后的攻击面、P2P 打洞成功率与 DERP 延迟、自托管中继成本，以及与 trycloudflare 等临时隧道的适用边界。
正文整理

Tailscale 开源的 Tailcat 是一款类似 netcat 的工具，无需注册 Tailscale 或加入 Tailnet，一条命令即可在两台设备间建立临时加密隧道。它优先尝试 P2P 直连，失败时走可自托管的 DERP 中继，支持收发数据、传文件、端口转发和 Exit Node/SOCKS 模式；其中 Exit Node 实测不稳定。其最大特点是即开即用、用完即抛，适合 AI Agent 等临时连接场景。
