手里攒了 20 多个 Pro 账号，我总结了这 7 种用法

查看原文 原文链接
点评旧认知是“Pro 会员 = 一个聊天窗口的额度”，读完后的增量是把它看成一组按产品分账的资源：AI Studio 网页会员用量、Flow credits、外部软件填 API Key 的计费是三套独立规则，日额度和月额度都不结转，返工和多候选也照常扣费。这套“先盘点权益与到期日、再按生产流程而非按工具组织用法”的思路，可迁移到任何订阅套娃、多平台额度混用的场景。下一步可验证：用一条 20–30 秒小片跑通全链路，记录提示词、额度消耗与返工次数，判断瓶颈究竟是额度不够，还是某一步还没练熟。
正文整理

作者把手头 20 多个 Google AI Pro 账号中的几个反代进 Codex，让 Gemini 3.8 Flash 在熟悉的环境里调用已有的视频 Skill，并顺势梳理出 7 种用法：确认订阅权益与到期日、视频逆向反推分镜、Flow 免费生图配合插件批量出图、ChatCut 剪辑与 Remotion/HyperFrames 代码视频、Deep Research 查资料、NotebookLM 做文章课件 PPT 与讲解视频、以及用编程能力做批量脚本。文中同时标注了第三方反代的账号封禁风险，以及网页会员用量、Flow credits 与 API 计费三套互不相通的额度边界。
