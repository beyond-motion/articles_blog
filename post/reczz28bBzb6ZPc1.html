合并的冲动：当 ChatGPT 遇上 Codex

查看原文 原文链接
点评旧认知是「选一个最强模型一直用」，新认知是模型要分层雇佣：规划者与执行者分离，价值在于编排而非单点能力。可迁移到任何多工具协作场景——写作、设计、数据分析都可以用同一份「简短说明+客观验收标准+批准闸门」的模板，把不确定性交给强模型、把工作量交给便宜模型。另一个增量是把厂商促销期视为窗口而非常态，趁窗口做横向评估。下一步可验证：挑一个边界清晰的小任务（如给仪表盘加 CSV 导出并跑通现有测试），记录强模型返工比例，若返工过半则证明降本尚未成立。
正文整理

OpenAI 将 Codex 并入新的 ChatGPT 桌面应用，Chat 与 Work 三种模式并存；Anthropic 随后延长 Fable 的促销访问并放宽 Claude Code 限额，双方都在争夺「代理式工作」的入口。文章记录了 Codex 老用户对合并的强烈反弹，指出这是一场用 500 万高级用户换 8 亿周活用户的赌注；同时给出「让 Fable 指挥更便宜的 Sonnet 或 GPT-5.6 Sol 执行」的具体工作流，并引用研究说明代理复用已验证方法可降错 53%。
